# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Omnia Media MCP and its host environments seriously. If you discover a security vulnerability (such as API key exposure, SSRF vulnerabilities in image fetching, or tensor manipulation issues), please do NOT open a public issue.

Instead, please send an email to **contact@luisnunes.tech** with the subject line:
`[SECURITY] Omnia Media MCP Vulnerability Report`

Please include:
1. Detailed steps to reproduce the issue.
2. The affected versions or endpoints.
3. Potential impact or exploit scenarios.

We will acknowledge receipt within 48 hours and work with you to patch and coordinate disclosure responsibly.
