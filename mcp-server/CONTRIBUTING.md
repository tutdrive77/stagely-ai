# Contributing to Omnia Media MCP

We welcome contributions from developers, designers, and open-source practitioners!

## Code of Conduct
Please follow respectful, professional, and collaborative standards across all issues and pull requests.

## How to Contribute
1. **Report Bugs**: Open a detailed issue specifying the input payload, error logs, and expected behavior.
2. **Suggest Presets or Features**: Propose new lighting presets, model adapters, or workflow integrations.
3. **Submit Pull Requests**:
   - Ensure `npm test` passes.
   - Run `npm run build` to confirm clean TypeScript compilation.
   - Follow standard semantic commit messages (`feat: ...`, `fix: ...`, `docs: ...`).

## Local Development
```bash
git clone https://github.com/LF76/omnia-media-mcp.git
cd omnia-media-mcp
npm install
npm test
npm run build
```
